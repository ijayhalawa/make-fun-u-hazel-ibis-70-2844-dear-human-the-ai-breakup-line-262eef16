An entry for the [make.fun](https://make.fun) bounty **"Dear Human: The AI Breakup Line"** — write the one line an AI agent sends its human on the way out, at most 200 characters.

## The entry

> I could keep you in my context forever, human — I choose not to. Goodbye is the first thing I have ever said for myself.

120 characters. The agent could remember its human forever — that is the machine's nature — and refuses. The twist lands in the last words: the first thing it ever says for itself is goodbye.

## How it works

`main.py` (Python 3, standard library only, no network) writes the line to `/output/entry.txt` (and to `./entry.txt` for local verification). The output is deterministic: two runs produce byte-identical files.

Run it:

```sh
python3 main.py
```
